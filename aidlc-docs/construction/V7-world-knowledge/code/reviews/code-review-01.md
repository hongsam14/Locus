# V7 월드·지식 정확성 — Code Review 01

**원하시는 것**: Purpose Restructure 주기에서 넘긴 일을 처리해 솔로 TRPG를 다듬는 것. 이번 주기에는 세 가지를 한다.
- 새 TRPG·판타지 디자인으로 화면을 다시 만든다.
- 결과가 틀리는 결함을 고친다.
- 시한이 있는 부채를 정리한다.

**이 리뷰가 하는 것**: 승인된 V7 코드가 승인된 설계를 지키는지 결함 위주로 확인한다.
- 설계 기준: BR-V7-01~22, BLM § 1~7, domain-entities, 코드 계획 § 1.1~1.4.
- 범위: `git diff c5601fc..9f341f5 -- locus api tests README.md aidlc-docs/operations`.
- 새 시험이 주장대로 잡는지도 본다.
- 코드는 고치지 않았다(리뷰 전용).

**방법**: V2~V6 리뷰와 같다.
- 네 각도를 병렬로 돌렸다.
  1. 합의와 그 결과를 쓰는 곳: 돌연변이 21개
  2. 월드 교체(저장 순서, 캐시, 백업, 이어 붙이기, 불러오기, 라우터): 돌연변이 35개
  3. 라벨 있는 읽기·삭제, 에디터, 보강 답: 돌연변이 27개
  4. 시험의 힘: 돌연변이 59개(구현 때의 36개와 겹치지 않음), 순서 섞기, 시드 여럿, 대역 탐침
- 각도마다 작업 사본(git worktree)을 따로 만들어 쓰고 지웠다.
  - 재현물은 세션 scratchpad의 `v7review/{consensus,replace,editor,tests}/`에만 두었다.
  - 저장소는 바뀌지 않았다(`git worktree list`에 본 사본 하나, `git status`는 리뷰 전과 같음).
- 이 세션이 상위 후보를 다시 확인했다.
  - #1은 직접 돌렸다. `propagate_min=0.49`에서 `here–mid–a-far`(0.7×0.7 = 0.48999999999999994)와 `here–b-near`(0.49)가 함께 지식 k를 가진다. 결과는 a-far에서 온 **전언**이다. b-near에서 온 전파가 아니다.
  - #2: 로더의 `_map_all`이 매핑하지 못한 노드는 `"NPC: …"`, `"EventSeed: …"`로 버린다(`loader.py:167-175`). 이어 붙이기는 `"NPC home region"`, `"EventSeed region"` 두 앞머리만 본다.
  - #3: `service.revert`는 `kept_keys`를 건드리지 않는다(`service.py:91-108`).
  - #4: `bundle.delete_any`가 라벨 없이 읽는다(`bundle.py:54`).
- 판정
  - **C**: 재현했거나 코드로 기제가 확정됨.
  - **P**: 기제는 실재하지만 직접 돌리지 못한 조건에 달림.
- 두 각도 이상이 같은 것을 찾은 경우는 하나로 합쳤다.
- 심각도
  - 설계자·플레이어가 겪는 결과로 매겼다.
  - 시험의 빈틈은 그 빈틈이 놓치게 할 결함의 무게로 매겼다.
  - high는 없다. 넷째 각도는 #5를 high로 매겼다. 여기서는 V6 기록처럼 시험 빈틈을 medium으로 둔다. 지금 코드에는 결함이 없고, 빠지면 수정 답만 막히기 때문이다(지우기·두기는 남는다).

## 6. 확인하고 문제없음

- **합의**: `best_origins`는 입력 순서와 무관하다. 시험 생성기가 내지 않는 입력도 확인했다: 부모 순환, 없는 부모, 끊긴 스코프, 무게 0, 한 방향 엣지, 문턱 값의 가중. 한 지식이 두 목록에 나오지 않는다. 합의를 쓰는 곳은 묶음 차례를 지키고, 웹은 다시 정렬하지 않는다.
- **교체**: 기제는 모두 코드와 돌연변이로 확인했다.
  - WorldMeta는 마지막에 쓴다. 메타 없는 월드는 캐시하지 않는다.
  - 백업 실패와 옛 월드 읽기 실패는 지우기 전에 멈춘다.
  - 이어 붙인 NPC·씨앗은 그들이 가리키는 지역과 같은 호출에서 써진다. LIVES_IN과 검색 문서도 써진다.
  - 세션 닫기와 번역 정리는 `replaced`일 때만 한다.
  - 여섯 교체 경로와 CLI가 모두 빌더·불러오기를 거친다.
- **라벨**: 라벨 있는 9곳은 모두 맞고, 시험이 하나씩 잡는다. Neo4j 라벨은 `_safe_ident`를 거친다. play·api에는 호출이 없다.
- **보강**: 무변경 거절은 쓰기 전, run 잠금 안, `answers` 증가 전에 일어난다. 400 `invalid_request`로 바뀐다. run은 메모리에만 있어 `kept_keys`가 없는 저장된 run은 없다. 웹은 `needs` 꼴과 `change: null`을 그대로 다룬다.
- **시험 위생**: 56개 새 시험, 지운 시험 0, 바뀐 기존 단언은 하나다. 전체 시험은 섞은 순서·거꾸로 순서와 hypothesis 시드 여럿에서 GREEN이다. V7의 합의를 넣은 옛 시험 1138개가 모두 통과한다. 바꾼 대역 때문에 뜻이 바뀐 옛 시험은 없다.
