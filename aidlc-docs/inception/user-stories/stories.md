# User Stories — Locus

**형식**: INVEST 기준 / Given-When-Then 수용 기준(AC) / 우선순위 P0(필수)·P1(권장)·P2(차기)
**페르소나**: P1 내러티브 디자이너 · P2 월드/레벨 디자이너 · P3 NPC 런타임
**여정 단계**: ① 입력 → ② 생성 → ③ 검토·보강 → ④ 쿼리/소비

각 스토리: `As a … I want … so that …` + AC + 우선순위 + 페르소나 + 여정 + 추적성(FR/NFR).

## EPIC-1 — 멀티모달 자료 수집 (FR-A) · 여정 ①

### US-1.1 텍스트 메모에서 엔티티·관계 추출 — P0
- **As a** 내러티브 디자이너(P1), **I want** 비정형 메모를 입력하면 엔티티(장소·인물·사건·사물·관습)와 관계가 추출되길, **so that** 흩어진 설정이 구조화된다.
- **AC**
  - Given 자유 형식 텍스트 메모, When 수집을 실행하면, Then 엔티티 후보가 타입과 함께 추출된다.
  - Given 추출된 엔티티, When 결과를 보면, Then 엔티티 간 관계(예: 인물–거주–장소)가 후보로 제시된다.
  - Given 모호한 표현, When 추출하면, Then 각 항목에 confidence가 부여된다.
- **페르소나** P1 · **추적성** FR-A1, FR-A5

### US-1.2 지도 이미지에서 지형·지역 추출(VLM) — P0
- **As a** 월드/레벨 디자이너(P2), **I want** 지도 이미지를 넣으면 지역·지형(산맥·강·길)이 추출되길, **so that** 그림만 있는 지도가 데이터가 된다.
- **AC**
  - Given 지도 이미지, When VLM 해석을 실행하면, Then 지역 후보와 지형 피처가 위치 단서와 함께 추출된다.
  - Given 저해상/모호 이미지, When 해석하면, Then 저신뢰 항목이 보강 대상으로 표시된다.
- **페르소나** P2 · **추적성** FR-A2, FR-A5

### US-1.3 구조화 맵 포맷 입력 — P0
- **As a** 월드/레벨 디자이너(P2), **I want** GeoJSON/노드-엣지 JSON을 직접 넣으면 지역·연결이 그대로 구성되길, **so that** 정밀 입력이 가능하다.
- **AC**
  - Given 유효한 구조화 맵 파일, When 임포트하면, Then 지역 노드·연결이 해석 오류 없이 생성된다.
  - Given 스키마 위반 파일, When 임포트하면, Then 어떤 항목이 왜 거부됐는지 보고된다.
- **페르소나** P2 · **추적성** FR-A3

### US-1.4 컨셉아트 보조 단서 추출 — P1
- **As a** 내러티브 디자이너(P1), **I want** 컨셉아트에서 장소·분위기 단서가 추출되길, **so that** 시각 자료의 정보도 활용된다.
- **AC**
  - Given 컨셉아트 이미지, When 해석하면, Then 보조 단서(장소·분위기 태그)가 낮은 가중치로 후보화된다.
- **페르소나** P1 · **추적성** FR-A4

### US-1.5 실세계 자료로 상식 Wiki 구성(동일 파이프라인) — P1
- **As a** 디자이너(P1/P2), **I want** 실세계 지도·텍스트를 동일 수집 기능으로 넣으면 상식 Wiki(디지털 트윈)가 만들어지길, **so that** 가상 세계 해석의 prior가 생긴다.
- **AC**
  - Given 실세계 참조 자료, When 수집 파이프라인을 "wiki 모드"로 실행하면, Then 가상 세계와 동일 포맷의 상식 KB가 생성된다.
- **페르소나** P1, P2 · **추적성** FR-A6, FR-E1

## EPIC-2 — 토폴로지 생성 (FR-B) · 여정 ②

### US-2.1 지역 식별 및 계층 구조화 — P0
- **As a** 월드/레벨 디자이너(P2), **I want** 입력에서 지역이 식별되고 대륙>지방>마을>구역 계층으로 구성되길, **so that** 스코프 상속이 가능하다.
- **AC**
  - Given 지도/구조화 입력, When 토폴로지를 생성하면, Then 지역 노드가 계층 부모-자식 관계로 구성된다.
  - Given 계층 노드, When 조회하면, Then 각 노드의 상위 경로(대륙>…>구역)가 명확하다.
- **페르소나** P2 · **추적성** FR-B1

### US-2.2 지형 제약 반영 연결 그래프 — P0
- **As a** 월드/레벨 디자이너(P2), **I want** 지형(산맥·강·길·교역로)이 지역 간 인접·접근·단절로 반영되길, **so that** 지리적 현실성이 생긴다.
- **AC**
  - Given 지형 피처가 있는 지역, When 연결 그래프를 생성하면, Then 인접/접근/단절 관계가 엣지로 표현된다.
  - Given 산맥으로 가로막힌 두 지역, When 그래프를 보면, Then 직접 연결이 없거나 약함으로 표시된다.
- **페르소나** P2 · **추적성** FR-B2

### US-2.3 상식 Wiki 기반 연결 강도 가중 — P0
- **As a** 월드/레벨 디자이너(P2), **I want** 상식 Wiki가 연결 강도(가중치)를 산정하길, **so that** "산맥→교류 지연" 같은 prior가 자동 반영된다.
- **AC**
  - Given 두 지역 사이 산맥, When 가중치를 산정하면, Then 연결 강도가 낮아지고 근거(상식 Wiki 규칙)가 기록된다.
  - Given 교역로로 연결된 지역, When 가중치를 산정하면, Then 연결 강도가 높아진다.
- **페르소나** P2 · **추적성** FR-B3, FR-E2

## EPIC-3 — 온톨로지/지식 그래프 (FR-C) · 여정 ②

### US-3.1 엔티티·관계 지식 그래프 구성 — P0
- **As a** 내러티브 디자이너(P1), **I want** 추출 엔티티·관계가 지식 그래프로 구성되길, **so that** 세계관 지식이 질의 가능한 구조가 된다.
- **AC**
  - Given 추출된 엔티티/관계, When 그래프를 구성하면, Then 타입이 지정된 노드·엣지로 저장된다.
  - Given 중복 후보, When 구성하면, Then 동일 엔티티가 병합되거나 병합 후보로 표시된다.
- **페르소나** P1 · **추적성** FR-C1

### US-3.2 지식의 지역 스코핑(계층 상속) — P0
- **As a** 내러티브 디자이너(P1), **I want** 각 지식이 토폴로지의 지역 노드에 귀속되고 계층 상속되길, **so that** "어느 지역의 컨센서스인지"가 분명하다.
- **AC**
  - Given 지식 항목, When 스코핑하면, Then 하나 이상의 지역 노드에 귀속된다.
  - Given 상위 지역에 귀속된 지식, When 하위 지역을 조회하면, Then 상속된 지식으로 포함된다.
- **페르소나** P1 · **추적성** FR-C2

### US-3.3 상식 Wiki 기반 고증 지식 자동 생성 — P0
- **As a** 내러티브 디자이너(P1), **I want** 상식 Wiki를 참조해 추가 고증 지식이 생성되길, **so that** 입력에 없던 그럴듯한 디테일이 채워진다.
- **AC**
  - Given 분지 지형 지역, When 고증을 생성하면, Then "고온 기후" 같은 추론 지식이 근거·출처와 함께 추가된다.
  - Given 생성된 고증, When 검토하면, Then 사용자가 수용/거부할 수 있도록 별도 표시(생성 출처=Wiki)된다.
- **페르소나** P1 · **추적성** FR-C3, FR-E2, SC-4

## EPIC-4 — 컨센서스·왜곡 모델링 (FR-D) · 여정 ②④

### US-4.1 연결 강도 기반 공유·전파 범위 결정 — P0
- **As a** NPC 런타임(P3) (간접: P1 설계), **I want** 연결 강도에 따라 지식의 공유/전파/미지 범위가 정해지길, **so that** 단절 지역은 모름이 표현된다.
- **AC**
  - Given 강하게 연결된 인접 지역, When 컨센서스를 계산하면, Then 지식이 공유로 분류된다.
  - Given 단절 지역, When 계산하면, Then 해당 지식은 미지 또는 소문으로만 도달한다.
- **페르소나** P3, P1 · **추적성** FR-D1

### US-4.2 하이브리드 컨센서스 계산(정적+쿼리시점) — P0
- **As a** NPC 런타임(P3), **I want** 직접 보유 지식은 미리 저장되고 전파/소문은 쿼리 시점에 계산되길, **so that** 빠르면서 유연하다.
- **AC**
  - Given 그래프 생성 완료, When 전처리하면, Then 각 지역의 직접 보유 지식 스코프가 저장된다.
  - Given 지역 쿼리, When 호출하면, Then 전파·소문 범위는 토폴로지 순회로 그 시점 계산된다.
- **페르소나** P3 · **추적성** FR-D2, NFR-E1

### US-4.3 지식 왜곡 표현(confidence + variant) — P0
- **As a** 내러티브 디자이너(P1), **I want** 왜곡을 경미한 차이는 confidence로, 내용이 바뀐 소문은 variant 노드로 표현하길, **so that** 소문 문화가 사실적으로 표현된다.
- **AC**
  - Given 먼 지역으로 전달된 지식, When 모델링하면, Then 지역별 confidence가 낮아진다.
  - Given 내용이 변형된 소문, When 모델링하면, Then 별도 variant 노드가 `distorted_from`으로 원본과 연결된다.
- **페르소나** P1 · **추적성** FR-D3

## EPIC-5 — 상식 Wiki (실세계 디지털 트윈) (FR-E) · 횡단

### US-5.1 상식 Wiki 영속 저장·조회 — P0
- **As a** 디자이너(P1/P2), **I want** 상식 Wiki를 가상 세계와 동일 포맷으로 저장·조회하길, **so that** prior를 재사용·관리한다.
- **AC**
  - Given 구성된 상식 Wiki, When 저장하면, Then 가상 세계 그래프와 동일 스키마로 영속화된다.
  - Given 저장된 Wiki, When 조회하면, Then prior 규칙·엔티티를 탐색할 수 있다.
- **페르소나** P1, P2 · **추적성** FR-E1, FR-I1

### US-5.2 상식 Wiki 편집 — P1
- **As a** 디자이너(P1/P2), **I want** 상식 Wiki의 prior를 추가/수정하길, **so that** 우리 게임에 맞게 보정한다.
- **AC**
  - Given 부정확한 prior, When 편집하면, Then 변경이 저장되고 이후 해석에 반영된다.
- **페르소나** P1, P2 · **추적성** FR-E1, FR-E3

### US-5.3 재현 가능한 근거 기록 — P1
- **As a** 내러티브 디자이너(P1), **I want** Wiki 기반 추론에 근거(출처)가 기록되길, **so that** 왜 그런 고증이 나왔는지 추적된다.
- **AC**
  - Given Wiki 기반 생성 지식, When 검토하면, Then 어떤 prior/규칙에서 유래했는지 표시된다.
- **페르소나** P1 · **추적성** FR-E3, NFR-C3

## EPIC-6 — 지식 보강 Q&A (FR-F) · 여정 ③

### US-6.1 보강 질문 자동 생성(3 근거) — P0
- **As a** 내러티브 디자이너(P1), **I want** 시스템이 그래프 빈틈·모순(A), Wiki 충돌(B), 저신뢰 입력(C)을 찾아 질문을 만들길, **so that** 무엇을 보강할지 알 수 있다.
- **AC**
  - Given 인접인데 공유 지식 없는 지역, When 분석하면, Then 빈틈 질문이 생성된다.
  - Given Wiki와 충돌하는 입력(분지인데 한랭), When 분석하면, Then 확인 질문이 생성된다.
  - Given 저신뢰 추출 항목, When 분석하면, Then 확인 질문이 생성된다.
- **페르소나** P1 · **추적성** FR-F1, CL5

### US-6.2 인터랙티브 보강 루프 — P0
- **As a** 내러티브 디자이너(P1), **I want** 질문에 답하면 그래프가 보강되고 다음 질문이 이어지길, **so that** 대화로 완성도를 높인다.
- **AC**
  - Given 생성된 보강 질문, When 답변하면, Then 그래프가 갱신되고 변경이 추적된다.
  - Given 미해결 항목이 남음, When 루프를 계속하면, Then 새 질문이 제시되고 수렴 시 종료된다.
- **페르소나** P1 · **추적성** FR-F2, FR-F3, CL4

### US-6.3 보강 변경 이력·되돌리기 — P1
- **As a** 내러티브 디자이너(P1), **I want** 보강으로 인한 변경을 보고 되돌릴 수 있길, **so that** 실수를 복구한다.
- **AC**
  - Given 보강 적용 후, When 이력을 보면, Then 어떤 답변이 어떤 변경을 만들었는지 보인다.
  - Given 잘못된 보강, When 되돌리면, Then 그래프가 이전 상태로 복원된다.
- **페르소나** P1 · **추적성** FR-F2

## EPIC-7 — 검토·편집 UI (FR-G) · 여정 ③

### US-7.1 토폴로지·지식 그래프 시각화 — P0
- **As a** 디자이너(P1/P2), **I want** 생성된 토폴로지와 지식 그래프를 웹에서 시각적으로 보길, **so that** 한눈에 검토한다.
- **AC**
  - Given 생성된 그래프, When UI를 열면, Then 지역 토폴로지와 지식 노드/관계가 시각화된다.
  - Given 특정 지역 선택, When 클릭하면, Then 그 지역의 스코프 지식이 표시된다.
- **페르소나** P1, P2 · **추적성** FR-G1

### US-7.2 노드·관계·지식 편집 — P0
- **As a** 디자이너(P1/P2), **I want** UI에서 노드/관계/지식을 추가·수정·삭제하길, **so that** 자동 생성 결과를 보정한다.
- **AC**
  - Given 시각화된 그래프, When 노드/관계를 편집하면, Then 변경이 저장·반영된다.
  - Given 잘못된 편집(예: 고아 관계), When 저장하면, Then 검증 오류가 안내된다.
- **페르소나** P1, P2 · **추적성** FR-G2

### US-7.3 UI 내 보강 Q&A 수행 — P1
- **As a** 내러티브 디자이너(P1), **I want** 보강 질문을 UI에서 보고 답하길, **so that** 한 화면에서 검토·보강이 끝난다.
