## Project Overview

**Locus는 세계관 자료로 월드를 만들고, 그 월드 안에서 소문과 사건이 지형을 따라 퍼지며 지역마다 NPC가 다르게 아는 것을 직접 겪는 솔로 TRPG다.**

Under the hood it ingests a world's notes, maps and concept art and builds (1) a **connection-network topology** of regions and (2) a region-scoped **knowledge graph** of what an NPC living there would know (places, people, events, customs, rumors); a game-session layer on top runs turns, NPC dialogue, deeds, rumors and events over that static world. Purpose statement: `aidlc-docs/inception/requirements/purpose-restructure-requirements.md` §0 (README first line, `pyproject` description, here).

## Tech Stack & Layout
- **Backend**: Python 3.11+, Pydantic v2, FastAPI, Neo4j (graph) + OpenSearch (hybrid search) for the canonical world, **PostgreSQL (SQLAlchemy) for the game-session layer**, LangChain/LangGraph, OpenAI (provider-abstracted). Docker Compose.
- **Frontend**: `web/` — React 18 + Vite + TypeScript + Tailwind v4, react-router: `/` home (`routes/HomePage.tsx`, `features/home/` — `DemoCards`/`DemoCard` from the manifest, `MyWorlds`), `/play/:sessionId` (`features/play/` — `RegionScene`, `NpcList`, `ResultBand`, `ActionBar`/`ActionDock`, `MovePanel`, `PlayLog`, `DialoguePanel`/`TalkSheet`, placed by `PlayLayout`), `/gm/:sessionId` (`routes/GmPage.tsx`, `features/gm/` — `MapPane` + `WorldStateOverlay`, `TurnTools` + `TurnBand`, `GmTabs` — region (rumors, distortion, knowledge), events, seeds, record (timeline), deeds, `PlayerStrip`), `/editor/:worldId` (`routes/EditorPage.tsx`, `features/editor/` — `EditorHeader`/`FileActions`, `EditorMapPane`/`MapTools`, `RegionInspector`, unscoped/augment/wiki tabs). Shared: `layout/` (`AppShell` with `LangSwitch` and the LLM-off band, `MapPanelLayout`, `SplitView`), `map/` (`WorldMap`), `ui/` primitives, `hooks/` (`useResource`, `useAction`, `useTurnRun`, `useWorldNames`), `api/` (`http.ts`: `useReplaceConfirm`, `openSessionsOf`), `errors/describe.ts`, `format/`, `capabilities.ts`, `i18n/` (ko/en dictionaries, display language; server languages from `GET /api/langs`). See `web/README.md`.
- **Code**: `locus/` is five boundaries — `shared/` (models, config incl. `tuning.py` (Knowledge/World/PlayTuning), llm, storage ports/adapters, `text.py` (`one_line`), `wiring.py`) · `knowledge/` (consensus, propagation, loader, query, `cache.py` WorldCache) · `world/` (ingestion, topology, ontology, wiki, augmentation, `build.py` WorldBuilder, `carry_over.py` (NPCs and seeds across a rebuild), `editor/` (one editor per kind + `Editors` bundle; region delete order), `refs.py` (`ConnectionKey`, `NameRef`), `npc_drafts.py`, `worldfile/`, `demo/`) · `play/` (models, ports, storage incl. unit of work and `clock.py` (increasing timestamps), `write_section.py` (a GM write's read-modify-write), session/distortion services, `rumor/` (service, `generator`, `promotion`, `feedback`, `dynamics`), `event/` (service, `dynamics`, `suggester`, `seeds.py` SeedService), `turn/` (advancer = single turn entry point, guard, executor, budget, summary, `changes.py` per-region turn changes), `player/` (movement rules + PlayService), `npc/` (pure `scope.py` + `prompts.py`, `dialogue.py` NpcDialogueService incl. deed appraisal), `deeds/` (DeedService: records deeds and appraisals — the turn engine marks seeds and undoes a failed run's — stays, seeds, memories, void; `caps.py` LLM output length caps), `gm/narrator.py` (declaration narration), `rumor/spread.py` (pure one-hop spread planner), `turn/quota.py`, `region_knowledge.py` (`region_sources` = the consensus resolve shared by the NPC scope, the player screen and the session query; rumor drafting resolves on its own), `player/log.py` (pure player-log filter), `world_state.py` (GM overlay read), `event/suggest_context.py` (what the suggester sees)) · `localization/` (translation cache + service + translator). Each boundary exposes `assemble_<boundary>()` + a typed container in its `wiring.py`. `api/` is the composition root (`deps.py`, `errors.py`, `schemas.py` DTOs with `*_ko`, routers `world` (+ `world_editor.py`)/`knowledge`/`play`/`gm` under `/api/<name>`, `uploads.py` body-size middleware and image checks). `web/` (above) · `tests/<boundary>/` + `tests/test_boundaries.py` (import-matrix guard).
- **CLI**: `locus init-schema [--world] [--play] [--localization] | world build|export|import|demo|list` (aliases `build-world`, `export`). `world demo --list` / `world demo --name emberleaf --world <id>` loads a manifest demo's World File with no LLM (demos are data: `locus/world/demo/worlds/manifest.json`); `world build --world <id> --demo <name>` builds it from its sources (LLM); `world build` needs an LLM and self-distills the world's WikiPriors; replacing a world with open sessions needs `--force`.

## Build / Test / Run
```bash
pip install -e ".[dev]" && pytest              # backend (offline, mocked)
cd web && npm ci && npm test                   # frontend (vitest)
cp env.example .env                            # REQUIRED: set NEO4J_PASSWORD, SESSION_DB_PASSWORD (no insecure defaults)
./scripts/setup-volumes.sh                     # first run: ./data bind-mount dirs
docker compose --profile service up -d --build # everything (infra + app :8000 + web :3000); plain `up -d` = infra only
locus init-schema && locus world demo --name emberleaf --world emberleaf   # host dev: LLM-free demo
uvicorn api.main:app --port 8000 --workers 1   # API ; cd web && npm run dev for UI
```
Gates (all in CI, `.github/workflows/ci.yml`): backend — `ruff check` + `black --check` on `locus api tests scripts`, `mypy locus api` (0 errors), `pytest`; frontend — `npm ci`, `tsc --noEmit`, `vitest`; audit — `npm audit --omit=dev --audit-level=moderate` (0); images — both images build, the packaged demo loads, `import api.main`. Ports: infra (Neo4j, OpenSearch, PostgreSQL, Dashboards) listens on 127.0.0.1 only; app (`API_PORT`, 8000) and web (`WEB_PORT`, 3000) on every interface. A host port already taken: set `NEO4J_HTTP_PORT`/`NEO4J_BOLT_PORT`/`WEB_PORT` etc. in `.env`.

## Conventions
- All external I/O behind ports (GraphRepository/SearchRepository/LLMProvider/VLMProvider/EmbeddingProvider, the play stores and `PlayUnitOfWork` in `play/ports.py`, TranslationStore) — mockable; offline tests mock them.
- Boundary imports: shared ← knowledge ← {world, play}; localization → shared only; `locus/**` never imports `api`; play never imports localization (translations are applied in `api/schemas.py`). Enforced by `tests/test_boundaries.py`.
- `world_id` is a property on every node and search document, indexed and filtered on; it is not a partition — node ids are unique per label across all worlds. Each world holds its own Common-sense Wiki (WikiPriors). The designer-only cross-world prior search (`world/wiki/cross_world.py`) filters on a top-level `domains` field while the index keeps it under `meta.domains`, so it finds nothing today (next-cycle list); NPC build/query stays single-world.
