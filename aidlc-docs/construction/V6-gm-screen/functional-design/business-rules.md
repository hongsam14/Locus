# V6 GM 화면 — Business Rules

**원하시는 것**: Purpose Restructure 주기에서 넘긴 일을 처리해 솔로 TRPG를 다듬는 것. 이번 주기에는 세 가지를 한다.
- 새 TRPG·판타지 디자인으로 화면을 다시 만든다.
- 결과가 틀리는 결함을 고친다.
- 시한이 있는 부채를 정리한다.

**지금 하는 것**: V6 Functional Design. GM 화면이 지킬 규칙과, 각 규칙을 확인하는 방법을 정한다.

표기: **검증**
- 테스트: vitest
- 검사: vitest 안의 grep
- 캡처: 가짜 API 위 headless Chrome, 1280·390
- 사람: 캡처 Artifact와 B&T

## C. 쓰기와 다시 읽기

| ID | 규칙 | 근거 | 검증 |

## 캡처 계획 (사람 확인)

V4 캡처 도구(세션 scratchpad의 가짜 API 서버)를 GM 읽기·쓰기 응답으로 늘려 찍는다.
- 데이터: 데모 Emberleaf, 이름표·지식은 한국어, 키 없음
- 폭: 1280·390, 그리고 768 한 장

| 화면 | 상태 |
|---|---|
| GM 1280 | [지역] 탭(소문·왜곡) / 턴 진행 뒤 결과 띠 + [기록] 탭 "새로" / [사건] 탭 세 묶음 / [행적] 탭 / 세션 끝내기 확인 / 끝난 세션 |
| GM 390 | 위에서 [지역] 탭, 결과 띠, 세션 끝내기 확인 |
| GM 768 | [지역] 탭 한 장 |

- 캡처 Artifact 한 장에 1280·390 쌍으로 싣고, 가로 스크롤 값을 함께 적는다.
- 세계 상태 범례와 배지가 사람 말로 읽히는지는 사람이 캡처로 본다(BR-V6-27).
