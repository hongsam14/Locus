# V4 홈·플레이 화면 — Code Review 01

**원하시는 것**: Purpose Restructure 주기에서 넘긴 일을 처리해 솔로 TRPG를 다듬는 것. 이번 주기는 새 TRPG·판타지 디자인으로 화면 다시 만들기, 결과가 틀리는 결함 고치기, 시한 있는 부채 정리다.
**이 리뷰가 하는 것**: 승인된 V4 코드가 승인된 설계(BR-V4-*)를 지키는지 결함 위주로 확인한다. 범위는 `git diff b7db475..fce6741 -- web`이다. 화면이 말하고 보이는 것, 접근성, 새 테스트의 힘도 본다. 코드는 고치지 않았다(리뷰 전용).

**방법**: V2·V3 리뷰와 같은 방식이다.
- 네 각도를 병렬로 돌렸다.
  - 읽기와 턴 루프(훅)
  - 플레이 화면 조립, 대화, 행동
  - 홈과 서버 계약
  - 표기, 접근성, 테스트 힘
- 재현물은 세션 scratchpad의 `v4review/{hooks,play,home,display}/`에만 두었다. 웹 사본(`web/src` 복사 + `node_modules` 연결)에서 시험과 돌연변이를 돌렸다. 저장소 파일은 바꾸지 않았다.
- 이 세션이 상위 후보의 코드 자리를 다시 읽어 확인했다.
  - `useTurnRun.ts` `recheck`가 `running`을 세우지 않음
  - FD BLM § 2.2 "`view.turn_running`이거나 `running`이면 진행 표시"와 `TurnStatus`
  - `web/nginx.conf:44-47`(`/assets/`는 `try_files $uri =404`)과 `web/src`에 오류 경계 없음
  - `api/routers/world.py:140-150`(`replaced`면 `ok`와 무관하게 세션을 닫음)
  - `ui/Dialog.tsx:56`(첫 초점 지정 없음)과 `DialoguePanel`의 버튼 순서
  - `NewSessionForm.tsx:52`(`r.level` 원문)
  - `fr-d8.test.tsx`의 `container.textContent`(형제 노드가 붙음)
- 판정: **C** = 재현했거나 코드로 기제가 확정됨. **P** = 기제는 실재하지만 이번에 직접 돌리지 못한 조건에 달림.
- 두 각도 이상이 같은 것을 찾은 경우는 하나로 합쳤다.
