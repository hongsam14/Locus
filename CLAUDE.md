## Project Overview

**Locus는 세계관 자료로 월드를 만들고, 그 월드 안에서 소문과 사건이 지형을 따라 퍼지며 지역마다 NPC가 다르게 아는 것을 직접 겪는 솔로 TRPG다.**

Under the hood it ingests a world's notes, maps and concept art and builds (1) a **connection-network topology** of regions and (2) a region-scoped **knowledge graph** of what an NPC living there would know (places, people, events, customs, rumors); a game-session layer on top runs turns, NPC dialogue, deeds, rumors and events over that static world. Purpose statement: `aidlc-docs/inception/requirements/purpose-restructure-requirements.md` §0 (README first line, `pyproject` description, here).

## Tech Stack & Layout
- **Backend**: Python 3.11+, Pydantic v2, FastAPI, Neo4j (graph) + OpenSearch (hybrid search) for the canonical world, **PostgreSQL (SQLAlchemy) for the game-session layer**, LangChain/LangGraph, OpenAI (provider-abstracted). Docker Compose.
- **Frontend**: `web/` — React + Vite + TypeScript (map-overlay topology, edit, augmentation Q&A, **game sessions: SessionBar + the GameMaster hub `features/gm/GmHub`**, **home `routes/HomePage.tsx` with manifest demo cards `features/home/DemoCards`**, **player screen `features/play/` at `/play/:sessionId`** with NpcList + DialoguePanel + `LangToggle` + declaration box and NarrationCard, GM `features/gm/` (`GmHub` + Manual/Event/Seed/Distortion/Rumor/Timeline/Deed panels, `PlayerStrip`, `WorldStateOverlay`), `ui/CommitRange`, `ui/LlmNotice` + `capabilities.ts` (LLM-off), `api/http.ts` (`useReplaceConfirm`, `openSessionsOf`); ko/en dictionaries and the display-language state (server languages from `GET /api/langs`) in `src/i18n.ts`).
- **Code**: `locus/` is five boundaries — `shared/` (models, config incl. `tuning.py` (Knowledge/World/PlayTuning), llm, storage ports/adapters, `text.py` (`one_line`), `wiring.py`) · `knowledge/` (consensus, propagation, loader, query) · `world/` (ingestion, topology, ontology, wiki, augmentation, `build.py` WorldBuilder, `editor/` (one editor per kind + `Editors` bundle; region delete order), `refs.py` (`ConnectionKey`, `NameRef`), `npc_drafts.py`, `worldfile/`, `demo/`) · `play/` (models, ports, storage incl. unit of work, session/distortion services, `rumor/`, `event/`, `turn/` (advancer = single turn entry point, guard, executor, budget, summary), `player/` (movement rules + PlayService), `npc/` (pure `scope.py` + `prompts.py`, `dialogue.py` NpcDialogueService incl. deed appraisal), `deeds/` (DeedService: records deeds and appraisals — the turn engine marks seeds and undoes a failed run's — stays, seeds, memories, void), `gm/narrator.py` (declaration narration), `rumor/spread.py` (pure one-hop spread planner), `turn/quota.py`, `region_knowledge.py` (`region_sources` = the consensus resolve shared by the NPC scope, the player screen and the session query; rumor drafting resolves on its own), `player/log.py` (pure player-log filter), `world_state.py` (GM overlay read), `event/suggest_context.py` (what the suggester sees)) · `localization/` (translation cache + service). Each boundary exposes `assemble_<boundary>()` + a typed container in its `wiring.py`. `api/` is the composition root (`deps.py`, `errors.py`, `schemas.py` DTOs with `*_ko`, routers `world` (+ `world_editor.py`)/`knowledge`/`play`/`gm` under `/api/<name>`, `uploads.py` body-size middleware and image checks). `web/` (React + react-router: `/` world list `routes/HomePage.tsx`, `/editor/:worldId` with `features/editor/`, `/gm/:sessionId`, `/play`) · `tests/<boundary>/` + `tests/test_boundaries.py` (import-matrix guard).
- **CLI**: `locus init-schema [--world] [--play] [--localization] | world build|export|import|demo|list` (aliases `build-world`, `export`). `world demo --list` / `world demo --name emberleaf --world <id>` loads a manifest demo's World File with no LLM (demos are data: `locus/world/demo/worlds/manifest.json`); `world build --world <id> --demo <name>` builds it from its sources (LLM); `world build` needs an LLM and self-distills the world's WikiPriors; replacing a world with open sessions needs `--force`.

## Build / Test / Run
```bash
pip install -e ".[dev]" && pytest              # backend (offline, mocked)
cd web && npm ci && npm test                   # frontend (vitest)
cp env.example .env                            # REQUIRED: set NEO4J_PASSWORD, SESSION_DB_PASSWORD (no insecure defaults)
./scripts/setup-volumes.sh                     # first run: ./data bind-mount dirs
docker compose --profile service up -d --build # everything (infra + app :8000 + web :3000); plain `up -d` = infra only
locus init-schema && locus world demo --name emberleaf --world emberleaf   # host dev: LLM-free demo
uvicorn api.main:app --port 8000 --workers 1   # API ; cd web && npm run dev for UI
```
Gates: `ruff check` + `black --check` on `locus api tests`, `pytest`, `mypy locus api` (baseline 11), `tsc --noEmit`, `vitest`, `npm audit --omit=dev` (0). CI: `.github/workflows/ci.yml` (backend, frontend, audit, images). Host ports already taken (e.g. 7474/7687): set `NEO4J_HTTP_PORT`/`NEO4J_BOLT_PORT` etc. in `.env`.

## Conventions
- All external I/O behind ports (GraphRepository/SearchRepository/LLMProvider/PlayRepository/TranslationStore) — mockable; offline tests mock them.
- Boundary imports: shared ← knowledge ← {world, play}; localization → shared only; `locus/**` never imports `api`; play never imports localization (translations are applied in `api/schemas.py`). Enforced by `tests/test_boundaries.py`.
- `world_id` partitions every graph; each world holds its own Common-sense Wiki (WikiPriors). Cross-world prior reference is a designer-only, read-through search by shared domain tags (NPC build/query stays single-world).
- ruff + black (line 100); PBT (Partial) via hypothesis on pure functions/serialization.
